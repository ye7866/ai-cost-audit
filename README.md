# AI 成本体检

> 帮 AI 重度用户把每月账单砍下来，**并且换过去不出事**。

## 这是什么

一份 8 部分的报告：

1. 账单拆解（含单位成本，让你看出哪笔最浪费）
2. 场景盘点（你每天到底在干什么）
3. **场景 × 模型匹配矩阵**（哪个能换、哪个换了会出事）
4. 三档方案（稳妥 / 平衡 / 激进，你自己选）
5. 收益测算（保守/中性两档，每格你能自己核对）
6. 迁移清单（按周执行，每步可回滚）
7. **不可换清单**（明确告诉你哪些别动）
8. 风险声明

## 适合谁

每月在 AI 工具上花 50–500 美元、说不清钱花在哪的**个人开发者和小团队（2–10 人）**。

## 不适合谁

- 只想要"最便宜的 key"的 —— 请去买中转站，我们不碰这块
- 需要企业级合规审计的 —— 超出能力范围，会直接说不接
- 需要有人替你操作账号的 —— 我们不碰任何账号密码

## 现在免费做 3 份

**前 3 名免费**，唯一条件：允许把报告**脱敏后**作为公开案例。

之后恢复 199 元/份。

为什么要免费：我需要真实案例来验证这套方法管用。你不花钱，我拿案例，各取所需。

## 怎么申请

开一个 [Issue](../../issues/new)，标题写 `体检`，回答 3 个问题：

1. 你现在订了哪些 AI 服务？每月大概多少钱？
2. 主要用来做什么？（写代码 / 写作 / 图片 / 语音 / 自动化…）
3. 你最想解决什么？（省钱 / 稳定 / 怕被封号）

**不需要账号密码，只需要金额区间。** 敏感信息可以打码。

## 报告长什么样

看 [示例报告](reports/demo-report.md) —— 注意：**示例里的数字是虚构的，只用来展示结构**，不是真实客户数据。

## 我不承诺什么

- ❌ 不承诺具体省钱比例（会给区间和算法，你自己核对）
- ❌ 不承诺模型能力长期稳定（价格和能力月月在变，报告有效期 30 天）
- ❌ 不提供任何违反上游服务条款的方案（中转站、代充、共享号）

## 为什么信我

- 我自己是重度用户，账单是自己一笔笔对过的
- 报告里会明确告诉你**哪些不能换**——只说"全能换"的人不可信
- 全程不碰你的账号，只要账单
